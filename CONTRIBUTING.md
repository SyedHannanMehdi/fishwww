# Contributing

Thank you for your interest in contributing to **fishwww**!

## Getting Started

1. Fork the repository.
2. Create a new branch for your feature or fix:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. Make your changes, following the existing code style.
4. Commit your changes with a clear message:
   ```bash
   git commit -m "feat: describe your change"
   ```
5. Push to your fork and open a Pull Request against `main`.

## Guidelines

- Keep PRs focused — one feature or fix per PR.
- Write clear commit messages.
- Add or update tests where applicable.
- Update documentation if your change affects public APIs or behaviour.

## Reporting Issues

Please open a GitHub Issue with a clear title, description, and steps to reproduce (if applicable).
