# Contributing to fishwww

Thank you for your interest in contributing! Please follow the guidelines below to help keep the project organized and collaborative.

## How to Contribute

1. **Fork the repository** and create a new branch from `main`.
2. **Make your changes** with clear, focused commits.
3. **Test your changes** to ensure nothing is broken.
4. **Submit a pull request** describing what you changed and why.

## Code Style

- Follow the existing code style and conventions used in the project.
- Keep changes minimal and focused on the issue being addressed.

## Reporting Issues

- Search existing issues before opening a new one.
- Provide a clear description, steps to reproduce, and any relevant context.

## Pull Requests

- Reference the related issue number in your PR description (e.g. `Closes #23`).
- Keep PRs small and focused — one concern per PR.
- Be responsive to review feedback.
